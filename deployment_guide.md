# NeuroHire Deployment Guide

This guide provides step-by-step instructions for deploying the **NeuroHire** application in a production environment:
- **Frontend**: Next.js deployed on **Vercel**
- **Backend**: Node.js/Express deployed on **Railway**
- **Automation / Webhooks**: Self-hosted **n8n** deployed on **Railway**

---

## 📋 Prerequisites
Before starting, ensure you have:
1. A **GitHub** repository containing your project.
2. A **Vercel** account.
3. A **Railway** account.
4. Your configuration credentials (Firebase service account JSON, database URIs, API keys).

---

## 🚀 Step 1: Deploying the Backend on Railway

Railway is ideal for hosting the Express backend. Since the project is structured as a monorepo, we will configure Railway to build from the `/backend` subdirectory.

### 1. Create a Railway Project
1. Log in to [Railway](https://railway.app/).
2. Click **New Project** -> **Deploy from GitHub repo**.
3. Select your repository.
4. Click **Configure** before deploying, or let the initial build fail and go to settings.

### 2. Configure Service Root Directory
1. In your Railway dashboard, select the backend service.
2. Go to the **Settings** tab.
3. Scroll down to **General** -> **Root Directory**.
4. Set the **Root Directory** to `/backend`.
5. Railway will automatically find `package.json` in the `/backend` directory and deploy the Node application.

### 3. Add Environment Variables
Go to the **Variables** tab of your backend service and add the following environment variables:

| Variable Name | Description / Example Value |
| :--- | :--- |
| `PORT` | `5000` (Railway will assign this automatically, but you can set it) |
| `NODE_ENV` | `production` |
| `MONGO_URI` | `mongodb+srv://...` (Your production MongoDB Atlas URI) |
| `FIREBASE_SERVICE_ACCOUNT` | Paste the **entire JSON string** of your Firebase Admin SDK service account credentials. |
| `OPENROUTER_API_KEY` | `sk-or-v1-...` (Your OpenRouter API Key) |
| `NANOBANANA_API_TOKEN` | `b7ea100b...` (Your Nanobanana API token) |
| `BACKEND_URL` | The public URL generated by Railway for this service (e.g., `https://backend-production.up.railway.app`). *Generate this under settings -> Public Networking.* |
| `FRONTEND_URL` | The public URL of your Vercel frontend (e.g., `https://neurohire.vercel.app`). |
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |
| `SMTP_SECURE` | `false` |
| `SMTP_USER` | `your-email@gmail.com` |
| `SMTP_PASS` | `your-smtp-app-password` |
| `SMTP_FROM` | `your-email@gmail.com` |
| `CONTACT_TO_EMAIL` | `your-email@gmail.com` |
| `JIRA_HOST` | `https://your-domain.atlassian.net` |
| `JIRA_USER` | `your-jira-email@example.com` |
| `JIRA_PROJECT_KEY` | `SCRUM` |
| `JIRA_API_TOKEN` | `ATATT...` |
| `N8N_WEBHOOK_URL` | The public n8n webhook URL for social media posts (constructed in Step 3). |
| `N8N_EMAIL_WEBHOOK_URL` | The public n8n webhook URL for interview invites (constructed in Step 3). |

## 🎨 Step 2: Deploying the Frontend on Vercel

Vercel is the recommended hosting platform for Next.js applications.

### 1. Create a Vercel Project
1. Log in to [Vercel](https://vercel.com/).
2. Click **Add New** -> **Project**.
3. Select your GitHub repository.

### 2. Configure Monorepo Settings
1. Next to **Root Directory**, click **Edit** and select the `frontend` folder.
2. Vercel will automatically detect the **Next.js** framework preset.

### 3. Add Environment Variables
Expand the **Environment Variables** section and add:

| Variable Name | Value |
| :--- | :--- |
| `NEXT_PUBLIC_API_URL` | `https://your-backend-railway-url.up.railway.app/api` |
| `NEXT_PUBLIC_BACKEND_URL` | `https://your-backend-railway-url.up.railway.app` |
| `NEXT_PUBLIC_FRONTEND_URL` | `https://your-frontend-vercel-url.vercel.app` |

*Note: Replace `your-backend-railway-url.up.railway.app` with the actual public URL generated by Railway for your backend.*

### 4. Deploy
Click **Deploy**. Vercel will build and launch your Next.js frontend application.

## ⚙️ Step 3: Hosting n8n and Importing Workflows

We will host n8n on Railway to execute the background social media auto-posting and email dispatch workflows.

### 1. Deploy n8n on Railway
1. In your Railway dashboard, click **New** -> **Templates**.
2. Search for `n8n` and select the official **n8n** template.
3. Configure it and click **Deploy**.
4. Once deployed, Railway will generate a public URL for your n8n service (e.g., `https://n8n-production.up.railway.app`).
5. Open that URL and set up your owner credentials to log into the n8n editor.

### 2. Import Your JSON Workflows
You have two workflows saved in the [n8n_Workflows](file:///c:/Users/ALLAH/Desktop/NeuroHire/NeuroHire_Project/n8n_Workflows) directory.

#### Workflow A: Job Post to Social Media
1. In n8n, click **Workflows** -> **Add Workflow** (or click the **+** button).
2. Click the three dots (top-right menu) -> **Import from File**.
3. Select [Job Post to Social Media.json](file:///c:/Users/ALLAH/Desktop/NeuroHire/NeuroHire_Project/n8n_Workflows/Job%20Post%20to%20Social%20Media.json).
4. Double-click the **Webhook** node to see its path (e.g. `job-post`).
5. Double-click the **HTTP Request** or integration node to configure any credentials if required.
6. Click **Save** and turn the toggle in the top-right to **Active**.

#### Workflow B: NeuroHire - Send Interview Emails
1. Click **Workflows** -> **Add Workflow**.
2. Click the three dots -> **Import from File**.
3. Select [NeuroHire - Send Interview Emails.json](file:///c:/Users/ALLAH/Desktop/NeuroHire/NeuroHire_Project/n8n_Workflows/NeuroHire%20-%20Send%20Interview%20Emails.json).
4. Double-click the **Webhook** node to see its path (e.g. `send-interview-emails`).
5. Double-click the **Send Email** node, and configure your SMTP credentials inside the node.
6. Click **Save** and turn the toggle in the top-right to **Active**.

### 3. Connect Webhook URLs to Backend
For n8n, webhook URLs follow this structure:
- **Test Webhook URL** (used when designing/testing inside n8n):
  `https://your-n8n-railway-url.up.railway.app/webhook-test/[path]`
- **Production Webhook URL** (active in the background):
  `https://your-n8n-railway-url.up.railway.app/webhook/[path]`

Get the production Webhook URLs from your n8n editor and set them as environment variables in your **Railway Backend Service**:
1. Set `N8N_WEBHOOK_URL` to `https://your-n8n-railway-url.up.railway.app/webhook/job-post`
2. Set `N8N_EMAIL_WEBHOOK_URL` to `https://your-n8n-railway-url.up.railway.app/webhook/send-interview-emails`

*Redeploy your Railway backend service to apply these variables.*

## 🔒 Firebase Service Account Stringification Note
For the `FIREBASE_SERVICE_ACCOUNT` environment variable on Railway:
1. Open your `neurohire-c4e9f-firebase-adminsdk-fbsvc-75140c9924.json` file.
2. Copy the entire text contents.
3. Paste it directly as the value of the `FIREBASE_SERVICE_ACCOUNT` variable in Railway. 
4. The backend is configured to automatically parse the raw JSON string from `process.env.FIREBASE_SERVICE_ACCOUNT` if it's set.
